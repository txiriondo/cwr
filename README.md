# FlorCWR

Aplicación de campo para el registro de poblaciones de recursos fitogenéticos silvestres (CWR) en reservas genéticas, orientada a su conservación in situ. Especie a partir del Catálogo Nacional PSC/PSUA (MAPA), GPS, polígonos de reserva, hábitats EUNIS, malla UTM ETRS89 de frecuencia de ocupación y estimación de abundancia por censo, transecto o frecuencia. Funciona sin conexión como PWA instalable.

## Instalación / alojamiento
Sirve los archivos por HTTPS (p. ej. GitHub Pages) y abre `FlorCWR.html` en el móvil; instálala en la pantalla de inicio. Consulta la guía de instalación y uso para más detalle.
